Paper Mario 64 — Traduzione Italiana (v4)

Patch di traduzione italiana completa per **Paper Mario 64** (Nintendo 64).
Traduce tutti i dialoghi del gioco in italiano, mantenendo intatti grafica, musiche e gameplay.

⚠️ Requisito fondamentale: serve la ROM AMERICANA

La patch funziona **solo** con la ROM originale americana:

- **Paper Mario (USA) v1.0** in formato `.z64` (big-endian)
- MD5 della ROM pulita: `a722f8161ff489943191330bf8416496`

Le versioni europea o giapponese **non** sono compatibili: la patch verrà rifiutata o produrrà una ROM corrotta.

> 💡 Come verifico la mia ROM? Usa un programma come **7-Zip** (tasto destro → CRC → *) o **HashMyFiles** e confronta l'MD5 con quello qui sopra. Se non corrisponde, la ROM non è quella giusta.

📦 File della patch

| File | Per quale ROM | Dimensione |
|---|---|---|
| `Paper_Mario_64_Italiano_v4.bps` | ROM `.z64` americana pulita (MD5 `a722f8161ff489943191330bf8416496`) | 836.020 byte |
| `Paper_Mario_64_Italiano_n64_v4.xdelta` | ROM `.n64` byteswapped / formato v64 (MD5 `5c0efad77f07b5e754b2c1efa6764f79`) | 1.138.922 byte |

Scegli il file in base al formato della tua ROM:
- la tua ROM finisce con **.z64** → usa il file **.bps**
- la tua ROM finisce con **.n64** → usa il file **.xdelta**

🛠️ Come applicare la patch (.bps)

1. Scarica **Floating IPS** (Windows) oppure apri **Rom Patcher JS** nel browser (funziona su PC e telefono)
2. In Floating IPS: *File → Apply Patch*
3. Seleziona `Paper_Mario_64_Italiano_v4.bps`
4. Quando chiede la ROM, seleziona la tua ROM **Paper Mario (USA) .z64 pulita**
5. Salva la ROM patchata con un nuovo nome (es. `Paper Mario ITA.z64`) — così conservi l'originale
6. Gioca la ROM patchata sul tuo emulatore preferito (o flashcart)

🛠️ Come applicare la patch (.xdelta)

1. Scarica **DeltaPatcher** (Windows) oppure **xdelta UI**
2. In *Original file* seleziona la tua ROM **.n64** americana
3. In *XDelta patch* seleziona `Paper_Mario_64_Italiano_n64_v4.xdelta`
4. Premi *Apply patch* e salva la ROM risultante con un nuovo nome

✅ Verifica

Dopo aver applicato la patch, controlla che la dimensione del file scaricato sia corretta (vedi tabella sopra): se è diversa, il download è corrotto e la patch verrà segnalata come "broken". Riscaricala.

- Tutti i dialoghi del gioco sono tradotti in italiano
